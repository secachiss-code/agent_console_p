# История изменений

## 0.1.1 — Работа с Git (локальная реализация, 2026-11-06)

Рабочие сессии задач вместо привязки Git-окружения к отдельной вкладке:
общая история и чекпоинты, последовательная передача работы между агентами,
изолированные worktree для параллельных исполнителей и единое слияние результата
сессии в базовую ветку проекта.

- Добавлены `WorkSession`, миграции существующих workspace/вкладок и истории,
  сохранение нативных идентификаторов CLI, 14 RPC-методов и capability `work_sessions.v1`.
- Один агент на физический общий workspace: явная передача, проверка остановки,
  журнал намерения до остановки и восстановление после сбоя без запуска агента.
- История этапов и результаты исполнителей сохраняются независимо от вкладок.
  Восстановление файлов делает защитный снимок и сохраняет HEAD и индекс.
- Изолированные detached worktree, preview результата по OID, принятие в сессию,
  дедупликация успешного принятия, затем финальный merge/fast-forward/squash в базу.
- Git-экран получил контекст сессии, участников, историю и действия жизненного цикла.
  Вкладки сгруппированы по задачам; диалог создания выбирает сессию и изоляцию.
- Закрытие вкладки сохраняет копии. Архивирование останавливает агентов; удаление
  управляемой копии остаётся отдельным проверяемым действием. История и исходные
  коммиты после squash удерживаются refs; импортированные копии защищены.
- Версии пакета, исходников и ответа ядра согласованы: `0.1.1`; API контрактов `1.4.0`.
  Старое ядро требует перезапуска перед подключением нового UI.

[План, карта кода и точка возврата](plans/0.1.1-git.md).
Проверки и артефакты: [отчёт](artifacts/git-0.1.1/VERIFICATION.md).
Установка в систему и публикация релиза не выполнялись.

## 2026-11-05 — буфер обмена терминала

Код: `a23df0e` (перенесён и отправлен в `main`).

- Исправлен перехват Ctrl+Shift+C/V на уровне окна. Поля ввода сохраняют своё обычное редактирование.
- Ctrl+C копирует выделение, а без выделения остаётся прерыванием. Ctrl+V, Ctrl+Shift+V и Shift+Insert используют буфер рабочего стола через GTK.
- Добавлено контекстное меню терминала: копирование, вставка, вставка изображения, выделение всего; открывается также через Shift+F10.
- Добавлен общий для агентов маршрут PNG через ядро: приватный файл в рабочей копии, проверка чтения из контейнера, вставка пути без автоматического Enter. Лимиты: 8 МиБ PNG и 32 мегапикселя.
- Ожидающая вставка отменяется при потере фокуса, скрытии или закрытии вкладки.
- Проверки: 348 GUI/UI/smoke-тестов, 52 проверки ядра и контрактов; `tools/check.sh` пройден. Один длительный тест прокрутки исключён по действующей практике проекта.
- Пересобран `dist/aconsole_0.1.0_amd64.deb`; запуск распакованного пакета проверен.
- После сборки пакет установлен в систему через `dpkg` (2026-11-05, 16:47 UTC). Проверены статус `install ok installed`, совпадение всех 249 Python-файлов в каждом из окружений core/UI и запуск установленного приложения из `/opt/aconsole` в изолированном окне (exit 0). Открытые рабочие окна не перезапускались.

Сквозное распознавание PNG как вложения подтверждено в Codex. Cursor в проверенном черновике оставил путь текстом; Claude и OpenCode сквозную проверку не прошли из-за отсутствия запущенных/установленных окружений. Поэтому поддержка нативных вложений во всех четырёх CLI ещё не подтверждена.

Подробности, контрольная сумма и снимок запуска: [отчёт](artifacts/clipboard-2026-11-05/VERIFICATION.md).
