## Изменения

Общая шкала отступов: 2/4/6/8/12/16/24 px; радиусы: 8 px у элементов управления,
14 px у карточек, отдельный круглый вариант для индикаторов и капсул. Роли текста:
подпись, основной текст, заголовок. Размеры в em сохраняют масштаб системного шрифта;
терминал и моноширинные данные сохраняют пользовательское семейство шрифтов.

Токены объявлены в `src/aconsole/ui/style/__init__.py`. `stylesheet()` раскрывает их
в CSS до передачи Gtk.CssProvider. Это позволяет сохранить GTK 4.14/libadwaita 1.5:
приложение не требует CSS custom properties из более новой версии GTK. Все три
загрузчика стилей (приложение, инструмент Git-снимков и contrast GUI test) используют
одну функцию. Отступы, радиусы и размеры текста CSS переведены на токены; геометрия
контролов, теней и зазор под системные кнопки остаются самостоятельными размерами.
Существующие нативные GTK/Adwaita-контролы сохраняют системное оформление.

Сеть получает синюю метку, выход за worktree и правка защищённых файлов — янтарную,
удаление, публикация, секреты и повышение привилегий — красную. При сочетании рисков
побеждает самый строгий цвет. Тексты всех рисков сохраняются. Задержка кнопки
«Разрешить» и правила согласования не менялись.

У пустых окон единый класс, значок новой вкладки и компактная основная кнопка по
центру. Стартовые страницы используют те же отступы. Аудит CSS-классов сохранён в
class-audit.json: неизвестных неиспользуемых классов нет; отдельно учтены динамические
классы NodeStatus, quota_level, статуса вкладки и Git refs.

## Визуальная проверка

Применён gtk-screenshot-review. Использован отдельный Xvfb с Xauthority и временными
XDG-каталогами; снимки сделаны из текущего worktree существующим GTK-окружением хоста.
Это established fallback APR-1/APR-2: hostrun snapshots не дают подходящего запуска
этого worktree. Xvfb извлекается во временный каталог без установки пакета.

Сняты и открыты 27 итоговых изображений приложения и 3 эталона тестовых виджетов.
Тексты локализованы, кнопки решений доступны при 700 px, геометрия совпадает между
темами, у тёмных карточек нет светлых вставок. Граф плана прокручивается по горизонтали
в узком окне; выходящие за viewport узлы не являются обрезанием неподвижного контрола.
За пределами отдельных диалогов PNG прозрачен — это не чёрная поверхность приложения.

### Surprises & Discoveries

- Первые снимки плана и Git перекрывались тестовыми согласованиями. В screens.txt
  фикстура убирает несвязанные pending approvals, страницы пересняты полностью.
- FakeCore не наполняет новую Git-историю. Дополнительно снята реальная история через
  tools/git_snapshot.py: временный репозиторий и отдельное настоящее ядро, без работы
  с пользовательским репозиторием.
- У пустого окна кнопка растягивалась на всю ширину. Добавлены центрирование, общий
  значок и акцентное оформление; три снимка пересняты и открыты повторно.
- Первый запуск baseline-фикстуры ошибочно передавал tabs в QuotaCard.set_accounts;
  исправлен вызов фикстуры. Приложение не менялось ради этого отказа.

## Эталоны и воспроизведение

`tests/gui/style_preview.py` строит настоящие ApprovalCard/PlanGraph/PlanCard/QuotaCard.
Таймер, шрифт, локаль, масштаб и анимация фиксируются только в этой фикстуре; работающие
агенты не запускаются. Эталоны находятся в tests/gui/snapshots/DES3. Они покрывают
общие стили виджетов, а не все состояния всех страниц приложения.

Тест декодирует оба PNG, сверяет размеры и каналы, затем сравнивает пиксели. Допускается
не более 0.1% каналов с разницей больше 8/255. Сдвиг изображения на 24 px отвергается.
Эталоны не перезаписываются тестом. Старые smoke-проверки существования PNG сохранены,
но не используются как свидетельство визуального совпадения.

Среда эталонов: GTK 4.14.5, libadwaita 1.5.0, DejaVu Sans 10 (fonts-dejavu-core 2.37-8),
X11, Cairo, scale=1, UTC. Другая тема, версия библиотек или шрифта может потребовать
явного пересмотра эталонов; автопропуска по платформе нет.

```sh
distrobox-host-exec <ui-python> <worktree>/artifacts/des3/runner.txt --tests-only
# Короткая финальная проверка:
distrobox-host-exec <ui-python> <worktree>/artifacts/des3/runner.txt --tests-only --focused
# Повторить визуальную проверку:
distrobox-host-exec <ui-python> <worktree>/artifacts/des3/runner.txt --captures-only
distrobox-host-exec <ui-python> <worktree>/artifacts/des3/runner.txt --screens-only
distrobox-host-exec <ui-python> <worktree>/artifacts/des3/runner.txt --git-only
# Только намеренное обновление эталонов после просмотра:
distrobox-host-exec <ui-python> <worktree>/artifacts/des3/runner.txt --record-baselines --captures-only
```
