# Неизменяемое окружение Tier 3

Направление хранит `gate_profile.environment.container` и
`gate_profile.environment.image` (реальный ID образа: 64 hex-символа,
с необязательным префиксом `sha256:`). Эти поля входят в замороженный контракт.
Контейнер проверок выбирается независимо от контейнера рабочей вкладки агента.

Ядро проверяет фактический образ перед поиском квитанции и после исполнения.
Для квитанции учитываются образ, ID контейнера, конфигурация и mounts.
Замена контейнера или образа не наследует старый PASS. Проверки выполняются по
проверенному ID контейнера, а не повторно разрешаемому имени.

Требования:

- read-only rootfs, без privileged и добавленных capabilities;
- единственный bind mount — интегрированный checkout по тому же абсолютному
  пути, только для чтения;
- дополнительные mounts допустимы только как scratch tmpfs `/tmp` и `/run`;
- инструменты и их Python-интерпретаторы находятся в образе; bind/volume с
  внешними инструментами отклоняется, даже если он объявлен read-only;
- `.venv`, `.venv-core`, `.venv-ui` в checkout отсутствуют либо являются прямыми
  абсолютными ссылками в `/opt/aconsole/` образа. Выход через `..` запрещён;
- кэши Ruff/XDG и временные файлы пишутся в `/tmp/aconsole-gates`, bytecode
  отключён, пользовательские Python site-packages не загружаются.

Для неизменённого `tools/check.sh` образ должен содержать среды
`/opt/aconsole/core` и `/opt/aconsole/ui`, а checkout — соответствующие ссылки
`.venv-core` и `.venv-ui`. Нельзя заменять существующие пользовательские среды
этими ссылками: использовать отдельный приёмочный checkout.

Пример запуска **уже подготовленного** образа; переменные задаёт оператор по
фактическому образу и отдельному checkout. Команды не скачивают зависимости:

```sh
podman create --name aconsole-gates-013 \
  --read-only --read-only-tmpfs=false --cap-drop=all --network=none \
  --user "${GATE_USER:?}" \
  --mount "type=bind,source=${GATE_ROOT:?},destination=${GATE_ROOT},ro=true" \
  --tmpfs /tmp:rw,nosuid,nodev --tmpfs /run:rw,nosuid,nodev \
  "${GATE_IMAGE:?}" /usr/bin/sleep infinity
podman start aconsole-gates-013
```

Обычный изменяемый Distrobox не удовлетворяет этому контракту. Если образ,
профиль или runtime не готовы, результат — `GATE_RUNNER_UNAVAILABLE`, без
запуска на хосте и без зелёной квитанции. Старые квитанции, созданные с
отпечатком `sh --version`, больше не совпадают с новым состоянием.

В этой работе новый OCI-образ не собирался и контейнер не запускался:
доступный Podman сообщил об отсутствии рабочего `conmon`, а host-spawn
не предоставляет рабочий запуск на хосте. Существующие контейнеры,
пользовательские venv и установленное приложение не менялись.
