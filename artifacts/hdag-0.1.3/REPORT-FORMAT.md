# Формат сохранённых отчётов

Перед первым коммитом из текстовых копий некоторых автоматически созданных
TXT/JUnit XML/.log удалены концевые пробелы для `git diff --check`. Вердикты, числа,
тексты ошибок и исходники не менялись. Полные байты этих файлов до нормализации
сохранены в `verbatim-reports.tar.gz` с относительными путями. JSON/JSONL evidence
и квитанции этой нормализацией не затрагивались.
