# DES-1 — приёмка гейта контраста

База: `68bf72ce`. Узел `plan-1/node-52`.
Существующее исправление: `c696a05f`.

## Результат

CSS и реализацию гейта менять не потребовалось. `tools/check.sh` вызывает
`contrast_check.py` без аргументов; `main([])` запускает проверку настоящего
style.css и terminal_palette.py. Ошибки дают ненулевой код, а не пустой успех.
Текст сравнивается с порогом 4.5:1, именованные значимые элементы — 3:1;
учитываются alpha, opacity, поверхности и tint состояний плана.

Добавлена прямая регрессия исходного дефекта запуска без аргументов:
на копии текущего CSS гейт возвращает 0, после добавления бледного текста
`#bbbbbb` возвращает 1 и указывает проблемный селектор светлой темы.
Рабочий stylesheet при проверке не меняется.
