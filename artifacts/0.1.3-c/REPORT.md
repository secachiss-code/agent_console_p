# AConsole 0.1.3+c — исправление профилей frozen-планов

Дата: 2026-11-16. Исходники пакета: `fd5fc80ac5c5a27e670d13b4695a740026220855`.
Ветка: `fix/frozen-plan-recovery-0.1.3-c`.

## Изменения

- `plan_save` и IPC `plan/save` принимают `repair_gate_profiles` для явного
  исправления неполных профилей старого frozen-плана. Требуются существующий
  `plan_id`, прежние title/goal и отсутствие `nodes`. Сохраняются ID, зависимости,
  fences, радиусы и история; хеши контрактов и ревизия пересчитываются. Решение
  записывается атомарно с планом. Отказы и ошибка записи сохраняют прежнее состояние.
- Исправление допускается до исполнения: без аренд и pipeline-попыток, при
  статусах pending/blocked. Корректные профили этим путём менять нельзя.
  Повтор одинаковой правки идемпотентен. Execute-вкладка права планирования не получает.
- Freeze проверяет профиль каждого L0, включая направления без дочерних задач.
- Исправлены строгая проверка типов обработчиков удаления плана, область Ruff
  и явное исключение для SQL-фикстур миграционного процесса.
- Ускорено декодирование повторяющихся OSC-сигналов: кэш живёт одно чтение,
  количество и порядок сигналов сохраняются. Неизменяемые сигналы используют slots;
  BEL не требует новой аллокации на каждое событие. Замер 64 КиБ: около 3,9 мс
  при сохранённом лимите 5 мс.
- Ожидание холодного запуска в тесте блокировки второго процесса согласовано
  с 20-секундным ожиданием клиента. Проверки отказа второго ядра и сокета сохранены.
- Обновлены JSON golden и версия в исходниках, lock и проверке пакета.

## Ограничения и применение

GUI не подтверждён в этом окружении: три UI-теста остановились при загрузке
`libgtk-4.so.1`, GUI-runner не получил Wayland socket. Изолированный импорт UI
в пакете не является проверкой окна.

Пакет готов к установке. Восстановление live plan-900 выполняется после обновления
из вкладки планирования через `repair_gate_profiles`, сразу для всех ошибочных L0.
Нужны проверенные argv и действительный образ devtools; старый sha256 из нулей
не подходит для запуска проверок. Команды и образ приложение не подставляет.
Прямые изменения пользовательской БД для восстановления не требуются.
