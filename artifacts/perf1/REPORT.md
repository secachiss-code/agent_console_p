## Результат

Оптимизация уже входит в текущий checkout. Повторная реализация не нужна:
дефект с прежними 5.29/6.26 мс после существующего исправления не воспроизвёлся.
Три последовательных `hostrun test core -k framer_speed` завершились exit 0,
каждый — 1 passed, Python 3.15.1, gil=False. Порог 0.005 с, пять попыток
и сам исходный tests/core/test_framer_speed.py не менялись.

Hostrun обслуживает основной checkout, поэтому до измерений сопоставлены
SHA-256 framer.py и test_framer_speed.py в нём и текущем worktree: оба файла
побайтово совпадают. Хэши сохранены в verification.json.

Отдельный прогон именно текущего worktree в devtools с его PYTHONPATH:

```
tests/core/test_framer_speed.py
tests/core/test_sidecar.py
tests/core/test_round6_k24.py
tests/core/test_sidecar_resilience.py
```

**42 passed**, 2.91 с. Подтверждены побайтовое сохранение OSC hyperlinks
и shell marks, сигналы OSC 0/2/9/777, progress, вложенные BSU/ESU,
разбиение маркеров во всех позициях, случайные разбиения Hypothesis,
таймауты/переполнение, линейный рост при 1 МиБ в chunks по 4 КиБ,
завершение PTY, сигналы, размер терминала и backpressure.
