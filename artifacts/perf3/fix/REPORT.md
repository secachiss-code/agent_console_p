# PERF-3: ограничить fault injection проверяемой остановкой

Дата: 2026-11-06. База: e3a9497, общий checkout main.

По ответу пользователя «продолжай» на конкретный вопрос о применении
artifacts/perf3/candidate.diff применена только предложенная правка:
writer._WAIT_S=0.03 задаётся после _connect, до намеренно блокирующей работы
writer.post и остановки. Это исключает startup из fault injection shutdown.
Значения 0.03, 0.15 и 2 секунды и все исходные assert сохранены;
равенство AST assert до/после проверено при применении.

Исходная ошибка: во время startup _restore_tabs -> PlanDatabase.load ->
Writer.call queued job получал тестовый deadline 30 мс и завершался до
открытия сокета. Изолированный исходный тест иногда проходил, а collection
полного набора воспроизводил отказ. Контрольный эксперимент: ../REPORT.md.

## Проверки

Команды последовательно через hostrun, HOSTRUN_CWD общий main.

| Набор | Exit | Секунды |
| --- | --- | --- |
| targeted | 0 | 30.165 |
| core | 0 | 251.961 |
| check | 0 | 42.624 |

Все три команды завершились exit 0.

Полные команды в results.json и hostrun-audit.json, вывод в targeted.txt,
core.txt и check.txt. Из вывода удалены только пробелы в концах строк.
Если ownership-подшаг check сообщает Not a git repository, он не считается
подтверждённым независимо от exit команды check; это известное ограничение.

Правка не меняет production-код, пороги производительности и логику writer.
Установленное приложение и настоящие CLI не перезапускались.

MCP claim PERF-3 продолжает возвращать PATHS_OVERLAP SEC-6. Пользователь
разрешил применение конкретного patch-кандидата после явного описания
резервов SYS-4/SEC-6; чужие lease и статусы напрямую не менялись.
Закрытие статуса узла требует доступного штатного перехода. PERF-2 остаётся
отдельным наблюдением о прежнем выбросе tick; его причина не установлена.
