## Воспроизведение

Из корня checkout в существующем host core окружении:

```sh
/path/to/.venv-core/bin/python artifacts/qa11/run.txt
/path/to/.venv-core/bin/python artifacts/qa11/run.txt --full
/path/to/.venv-core/bin/python artifacts/qa11/summarize.txt
```

`run.txt` отключает порог только для сбора данных тестового шага, как CI;
порог 90% из pyproject.toml сохранён и проверяется по объединённому результату.
Сырые coverage и логи локальны и игнорируются Git. JUnit и численные summaries
сохраняются в коммите. CI, установка deb, PERF-7 и независимая приёмка этим
узлом не заменяются. Приёмка DES-3 остаётся открытой.
