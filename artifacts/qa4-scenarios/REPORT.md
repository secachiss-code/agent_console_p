## Общие прогоны и ограничения

- Host core, Python 3.15.1 free-threaded: **2056 PASS, 1 FAIL, 1 SKIP,
  1 deselect**, 349.27 s, `core.xml`. Выбор `-m 'not performance'` соответствует
  coverage-шагу CI; отдельный performance-шаг этим запуском не проверен.
  Отказ `test_contracts_golden_bytes`: golden EditDetail не содержит нового
  поля `input_json: null` из APR-2 (`973e7e2c`). Это не зелёный core gate.
- Native Xvfb GUI, Python 3.15.1 GIL, английская локаль: **506 PASS, 1 FAIL,
  1 прежний deselect PERF-7**, 206.12 s, `full-ui-coverage.xml`.
  Отказ: `test_a_conflicted_rebase_offers_abort_and_a_stale_commit_is_refused`
  не дождался чистого worktree и исходного HEAD после abort.
- Тот же GUI-сценарий отдельно: **1 PASS / 286 deselected**, 7.83 s,
  `git-actions-focused.xml`. Причина полного отказа не установлена; создан QA-9.
  Положительный отдельный результат не заменяет отрицательный полный.
- В начале core и связанный набор были запущены внутри контейнера и прерваны
  без итогового отчёта после задержки. Причина зависания не установлена; PASS
  им не присваивается. На хосте core завершился. `host-spawn` вернул 127;
  рабочий способ запуска — `distrobox-host-exec`.
- Полный core собирал предыдущую редакцию нового теста недоступного файла.
  Финальная редакция проверяет публичный reader и исправный соседний файл;
  она повторно проверена в итоговых 47 PASS и входит в объединённое покрытие.
- CI, установка deb и доверенная независимая приёмка заново не запускались.
  DES-3 остаётся без пользовательской приёмки; SEC-11/PERF-7 не закрываются.

## Воспроизведение

Из корня рабочего дерева, на хосте с окружениями проекта:

```sh
/path/to/.venv-core/bin/python artifacts/qa4-scenarios/run-core.txt --readers
/path/to/.venv-core/bin/python artifacts/qa4-scenarios/run-core.txt
/path/to/.venv-ui/bin/python artifacts/qa4-scenarios/gtk-runner.txt --full-ui --coverage
/path/to/.venv-ui/bin/python artifacts/qa4-scenarios/gtk-runner.txt --git-actions
/path/to/.venv-core/bin/python artifacts/qa4-scenarios/summarize.txt --combined
/path/to/.venv-core/bin/python -m coverage report --data-file=artifacts/qa4-scenarios/.coverage.combined --precision=2
```

Последняя команда должна завершаться с ошибкой порога. Отказы общих прогонов
не препятствуют отдельному объединению покрытия. Xvfb извлекается во временный
каталог без установки системного пакета; тестовый HOME изолируется conftest.
Сырые `.coverage.*` и журналы остаются локальными игнорируемыми артефактами;
JUnit, summaries и точные списки покрытых строк/ветвлений сохранены в коммите.
