# SEC-3 — оставшиеся действия hostrun

База: `9498b18`, `plan-1/node-9`.

## Изменения

- `core-run` запускает Python проекта через `podman exec devtools`.
- `deps-sync` запускает создание venv и `uv sync` внутри devtools; обе версии
  Python, `--locked`, UI dependency group и UV_PROJECT_ENVIRONMENT сохранены.
  Изменяемый build backend больше не исполняется непосредственно на хосте.
- `ui-run` и `ui-snapshot` запускают прежние команды в devtools. Передаются
  DISPLAY, WAYLAND_DISPLAY, XDG_RUNTIME_DIR, XDG_CURRENT_DESKTOP, XAUTHORITY.
- `fake-core start/stop` вызывают контейнерный режим server.py. Прежние
  проверки PID/cmdline, ожидание сокета и остановка выполняются в том же PID
  namespace, что и fake-процесс. Host отслеживает только команду podman exec.
  Runtime передаётся явно, PID-файлы отделяются по агенту и сценарию.
- policy.example документирует контейнерное выполнение всех пяти действий.
  Named actions, allowlist аргументов и ограничения policy сохранены.

## Проверки

Полный набор `tests/hostrun` **текущего worktree**, запущенный непосредственно
в devtools: **198 passed, 1 skipped**, 20.18 секунды, exit 0.
Пропуск: `test_allowlist.py:50`, отсутствуют списки клиентов в linked `docs/`.

Новые тесты покрывают каждое действие и варианты UI/fake/deps, запрещённые
аргументы, HTTP-маршрутизацию только в podman и CLI контейнерного lifecycle.
Отдельная проверка создаёт настоящий временный Python-процесс с Unix-сокетом:
start, повторный start без дубля, stop, удаление PID-файла и завершение процесса.
Тестовый процесс и репозиторий удаляются; рабочее приложение не затрагивается.

`compileall` и `git diff --check` прошли. Ruff при явном запуске на этих обычно
исключённых файлах сообщает прежние 45 замечаний. Сравнение диагностики
по (код, сообщение) с базой: actions 8 → 8, server 35 → 35, test_server 2 → 2;
новых замечаний нет. Синтаксис Python 3.12 проверяется штатным тестом набора.

## Активация и ограничения

Изменения находятся в рабочей ветке. Действующий hostrun загружает код из
основного checkout; его policy и service не изменялись, перезапуска не было.
После интеграции для применения потребуется штатный перезапуск hostrun.

Живые GTK-окна и реальная установка зависимостей не запускались; проверены
маршрутизация и сохранение аргументов/окружения. Devtools должен иметь доступ
к workspace, runtime-сокетам и дисплею. Ранее запущенные на хосте fake-процессы
не мигрируются: их следует штатно остановить до переключения hostrun.
Доступ devtools к данным хоста относится к SEC-7, доверие review gate — к SEC-4.
