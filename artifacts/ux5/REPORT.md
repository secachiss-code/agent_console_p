# UX-5 — параметры новой вкладки и проекты

База: `c764b024`; plan-1/node-43.

## Изменения

Три режима рабочей копии уже присутствовали после предыдущих исправлений.
Сохранены новый worktree, основной checkout и существующий каталог. Для нового
worktree добавлено редактируемое поле базовой ветки, заполненное default_branch
выбранного проекта. Можно связать вкладку с узлом активного плана этого проекта.
TabsViewModel передаёт base_branch и plan_node существующему tab/open; для
повторного использования рабочей сессии новая базовая ветка не навязывается.

Во время открытия показаны spinner и «Открытие…», поля и повторное открытие
заблокированы. Ошибка видна внутри диалога и через существующий callback;
введённые значения остаются, доступен повтор. Содержимое диалога прокручивается,
заголовок с кнопкой открытия остаётся доступен.

Рядом с переключателем проектов появилась кнопка удаления из списка. Пока есть
вкладки проекта, она отключена с пояснением. Подтверждение сообщает, что файлы
останутся; вызывается существующий project/remove, без удаления worktree.
Подтверждение привязано к конкретному проекту, изменение активного проекта
не меняет адресата удаления. Отказ ядра показан в панели, список сохраняется.

UX-17 из objective также выполнен: в карточке согласования есть необязательное
пояснение при отказе. Оно передаётся через уже существующее DecideParams.message
и только для DENY. ALLOW и его scope не изменены. Изменения approvals panel/VM
выходят за первоначальный список paths узла и отмечены в его note.
Новых RPC-схем, режимов согласований или перестановки панели не добавлялось.

## Surprises & Discoveries / визуальная проверка

Применён gtk-screenshot-review. Просмотрены 12 PNG: new-tab, opening,
project-remove, deny-message — светлая/тёмная тема 1280×800 и светлая 700×800.

- hostrun относится к основному checkout, в devtools нет GTK. Использован
  нативный UI venv с приватным Xvfb, временными Xauthority/config/state/cache;
  пакет только извлечён во временный каталог без установки. Сценарии сохранены.
- Добавленные поля увеличили высоту диалога: body помещён в ScrolledWindow
  с ограничением natural height; при 700px поля и кнопка открытия доступны.
- Spinner, «Открытие…» и отключённые поля видимы. Подтверждение удаления
  содержит пояснение о сохранности файлов; кнопки не обрезаны.
- Поле пояснения отказа и кнопки помещаются при 700px. В тёмных видах нет
  светлых участков, видимых ключей перевода и нового clipping не обнаружено.
- В demo текст узла «Node 1» — название фикстуры, ключи интерфейса переведены.
- docs/design/DESIGN.md отсутствует: совпадение с отсутствующим макетом не заявлено.

Снимки используют FakeCore и искусственную задержку tab/open для busy-состояния.
Они не запускают агентскую беседу. Проверки удаления затрагивают только временные
проекты. Установленное приложение, пользовательские файлы и контейнеры не менялись.
