# AN-1. Доверие и изолированный запуск

Дата проверки — 2026-11-22. Базовый HEAD — `a1c93b9eacef5cfe980382b4f1686e996f7c8610`. Проверки выполнены на Linux x86_64 7.0.0-38-generic, Debian 13, Python 3.15.1 free-threaded. Для проверки на хосте использован Bubblewrap 0.12.0, извлечённый во временный каталог из пакета Debian. SHA-256 совпал с опубликованным для пакета. [Пакет Debian](https://packages.debian.org/trixie/amd64/bubblewrap/download)

## Решение

- Хранить доверие отдельно от таблицы проектов. Запись отсутствует у старых и новых проектов до явного назначения доверия. Профиль `build` проверяет флаг до передачи запуска адаптеру. Миграция создаёт таблицу с каскадным удалением при удалении проекта. Откат удаляет таблицу доверия и сохраняет возможность создавать проекты на прежней схеме.
- Указать `bubblewrap` в `Depends` пакета Debian. Перед каждым запуском выполнить ограниченный по времени probe с теми же точками монтирования и пространствами имён, что у целевой команды. При отсутствии исполняемого файла или отказе probe вернуть `CONFINEMENT_UNAVAILABLE`. Профили `static` и `build` требуют рабочей изоляции.
- Открывать дерево проекта только для чтения. Выделить отдельный scratch для записи, рабочего каталога, `HOME` и `TMPDIR`. Запускать с отдельными пространствами имён пользователя, сети и процессов. При отмене завершать группу и дожидаться выхода процесса Bubblewrap.

## Проверка

Команда контракта `hostrun test core tests/core/test_analysis_confinement.py tests/core/test_migration_worker.py` запускалась из рабочей копии. По умолчанию hostrun использовал основную копию, где тест AN-1 отсутствовал. При передаче пути текущей копии hostrun вернул `cwd escapes projects`. Целевые тесты выполнены напрямую на хосте.

```sh
ACONSOLE_TEST_BWRAP=/tmp/aconsole-an1-bwrap/usr/bin/bwrap PYTHONPATH="$PWD/src" \
  /home/sas/Projects/sp_aconsole_prototype/.venv-core/bin/python -m pytest \
  -q -o addopts='' -rs tests/core/test_analysis_confinement.py \
  tests/core/test_migration_worker.py tests/core/test_merge_migrations.py
```

На хосте прошли все 22 теста. Живой тест подтвердил отсутствие доступа к домашним данным, отдельное пространство имён сети, доступ к проекту только для чтения, запись в scratch и завершение дочернего процесса из отдельной сессии при отмене.

Проверки упаковки и защитных условий сборки выполнены через `pytest tests/test_packaging.py tests/test_build_guards.py` отдельными запусками. Прошли все 10 тестов. Для теста манифеста использован временный индекс Git с файлами AN-1. Ruff, basedpyright и шесть контрактов import-linter проверены локально.

## Остаточный риск

Живой прогон покрывает одну комбинацию ядра и Bubblewrap. На системах, где политика ядра запрещает необходимые пространства имён, анализ вернёт `CONFINEMENT_UNAVAILABLE`. Профиль изолирует IP-сеть. Проектные пути, доступные в песочнице, остаются границей доверия для файловых UNIX-сокетов, поэтому слой подготовки снимка должен подавать обычные файлы и каталоги.

В плане узел остаётся в `blocked` с `ATTEMPTS_EXHAUSTED`. Все четыре попытки сохранены. Штатный захват возвращает `NODE_TRANSITION_INVALID`. Обязательное ревью плана ожидает решения по открытому запросу `replan`.
