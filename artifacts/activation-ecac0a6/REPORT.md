## Прерывание и возобновление

После пользовательского «Стоп» хост перезагрузился: текущий kernel btime
2026-11-07T06:56:53Z позже времени активации. Первые повторные диагностики
пытались сравнить прежние PID и поэтому отказали. Это зафиксировано как
непригодная проверка между загрузками, а не скрыто как успешное сохранение PID.
Служебный codex-code-mode также завершился; это не отдельный CLI-агент.

Финальная проверка учитывает границу загрузки. Сохранены исходная вкладка
и её native session ID; установленные хеши совпадают с проверенным main.
Новый core работает из /opt/aconsole/core/bin/python3.15t. Фактический PID,
число вкладок и счётчик графа — в verification.json. Сохранность одинаковых
PID между перезагрузками не заявляется; при самой активации до перезагрузки
они были сохранены, что подтверждено отдельным after.json.

## Проверка установленного SEC-5

Отдельный /opt/aconsole/core/bin/python -I импортировал только установленный
ApprovalBook. Smoke подтвердил: разовый ALLOW не переносится на другую
вкладку с тем же event ID; другой вход требует нового запроса; drop_tab
удаляет только собственные записи, оставляя чужой pending/replay.
Smoke PASS. Это проверка установленного доменного кода в изолированном
процессе, без создания согласований или закрытия пользовательской вкладки.
Daemon wiring TabRemoved сверено по установленному bootstrap.py и его хешу.

Свежий host UI-role клиент по настоящему IPC подтвердил состояние приложения
и сохранённые done-узлы. Новых узлов не принимали, рабочую БД напрямую
не меняли. Полный1779PASS и targeted162PASS относятся к исходникам этого
пакета: artifacts/sec5/REPORT.md. Повторный полный набор здесь не заявляется.
