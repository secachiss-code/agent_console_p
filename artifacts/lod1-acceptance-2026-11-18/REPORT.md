# LOD-1 — контекст по дистанции графа

Замороженный контракт: 7c369e49df0e42b7667537d3129ac638c517ccfdaea9b2ad51bcb64efab657fe.
Узел node-908 плана plan-900, fence 2, attempt 2. Попытка 1 ранее оставлена
при ремонте scope; реализация выполнена в попытке 2.

Реализация:

- Прямой multi-root обход сохранённого графа отдельным рекурсивным UNION CTE,
  глубина до 3 и лимит 40 файлов. Рёбра imports/depends_on/inherits/implements.
  Обратный CTE радиуса проверок не изменён. Для transient-индекса — BFS.
- Корни — реальные файлы scope узла. Ромбы и циклы дают минимальную дистанцию;
  ограничение проекта действует на оба конца каждого ребра. Один файл с
  несколькими объявлениями получает объединённый список symbols.
- PipelineGit.context подключает граф к live-контексту: d=0 сохраняет прежний
  номерной срез, d=1 содержит Python AST-скелет или symbols экстрактора,
  d=2/3 — строку path/kind/symbols, d>=4 отсутствует. Пути упорядочены.
- Шейпер измеряет UTF-8 размер всего ответа (256 КиБ) до записи кэша и
  отметки доставки. Сначала удаляет d=3, потом d=2, затем длинные скелеты d=1.
  Contract, scope, hashes и обязательные поля handoff сохраняются.
  Повторная доставка учитывает тот же полный бюджет перед выбором digest.

Регрессии покрывают сохранённый и transient-граф, прямое направление,
несколько корней, ромб и цикл, границу d=4, виды рёбер, изоляцию проектов,
лексикографический лимит 40 файлов, реальную сборку контекста из worktree,
три стадии сокращения бюджета и повторную доставку. Строгая типизация
двух затронутых тестовых модулей исправлена без отключения диагностики;
wire-тест использует публичный CLI request_frame и штатный handshake.
