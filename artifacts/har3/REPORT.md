# HAR-3 — fork и выбор нативной сессии

База: `60275c63`; plan-1/node-36.

## Воспроизведение и изменения

Регрессия HAR-01 воспроизведена через экспорт/adopt вкладки: после восстановления
терялся флаг fork, команда становилась обычным resume родителя. Теперь
`fork_pending` хранится в БД (миграция 0008) и сохраняется до получения нового
нативного ID. После этого запускается resume дочерней беседы, ID родителя не
меняется. Пока fork ожидает дочерний ID, UI не выдаёт ID родителя за ID копии.

`session/list` маршрутизирован настоящим ядром. HostAgentCommands использует
существующие readers Claude/Codex и HTTP reader управляемых серверов OpenCode.
Каталог ограничен cwd проекта и его рабочих сессий, проверяет ID и сортирует
метаданные. Новая вкладка отдельно показывает CLI-сессию и рабочую сессию задачи;
выбор беседы подставляет её каталог. Запоздалые ответы чужого контекста отброшены.
Перед открытием ядро проверяет агент, каталог и наличие выбранной беседы.

Меню вкладки вызывает tab/fork и выбирает новую вкладку. Действие доступно только
при наличии исходного ID и capability fork. Resume проверяет capability и ID до
остановки агента; отсутствующий transcript Claude даёт SESSION_NOT_FOUND вместо
молчаливого запуска новой беседы. Кнопка Resume отключена при отсутствии ID или
поддержки. Cursor resume=False согласован с текущим README. Явное действие «Новая»
сбрасывает ID и pending fork.

terminal-ended в светлой/тёмной теме 1280×800 и светлой 700×800.

  Тёмные виды не имеют светлых участков, ключи переводов не показываются.

## Пределы проверки

Тесты используют реальные GTK, Daemon, Unix IPC, БД и формат метаданных CLI,
но не запускают оплачиваемую беседу с моделью. OpenCode каталог доступен при
работающем сервере, созданном текущим ядром; README отражает это ограничение.
Миграция сохраняет новые pending forks, но не восстанавливает уже потерянный
флаг у старых вкладок эвристикой по названию. Установленный сервис и контейнеры
пользователя не изменялись. Единичный отказ writer сохраняется как наблюдение
PERF-2 даже при успешном повторе.
