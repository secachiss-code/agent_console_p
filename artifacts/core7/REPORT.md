2026-11-06, общий main, база 4a487fc.

node_update теперь допускает отсутствие fence. Для перехода failed -> pending
передаётся именно отсутствие fence; domain rules остаются без изменений.
Новый node_claim выдаёт следующий fence, а старый fence продолжает отклоняться,
в том числе между release и следующим claim. Heartbeat без fence отклоняется.

удерживающей аренду, с актуальным fence. Проверка владельца учитывает, что
verifying не освобождается автоматически после обычного срока lease.
Изоляция проектов и запрет агенту принимать verifying -> done сохранены.
node_attach и его схема не менялись; это исправление касается node_update.
