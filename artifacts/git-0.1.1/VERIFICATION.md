Указанные полные прогоны ядра и GUI не были полностью зелёными:
оставшиеся таймаут сокета и гонка готовности bracketed paste успешно перепроверены
отдельно. Это не скрытые skip: число исходных отказов и повторов приведено выше.
Все остальные сценарии указанных полных прогонов прошли.

Во всех проверках использовались временные репозитории и отдельные данные.
Ядро — Python 3.15t без GIL; GUI — Python 3.15 с GTK хоста. Контейнер не содержит
нужной библиотеки GI, поэтому GUI запускался через private authenticated Xwayland,
без управления пользовательскими окнами. Два документальных check пропущены штатно:
внешний репозиторий `docs/contracts` не подключён. Длительный GUI-тест прокрутки
исключён по существующей практике проекта; unit-пороговые проверки Git выполнены.

Проверены передача и запрет второго запуска общего workspace, две независимые
изолированные launch reservations, отказ записи журнала до остановки агента,
восстановление незавершённых намерений без автозапуска, миграция legacy checkpoints,
сохранность HEAD/индекса при откате, dirty/stale preview, дедупликация интеграции,
сохранение новых непринятых коммитов при очистке, архивная очистка исполнителя,
полный путь result → integrate → squash → archive → cleanup с сохранением refs.

В завершающей проверке также исправлено обновление диалога новой вкладки:
при смене проекта старый выбор сессии очищается до обращения к новому списку.
GUI-тест воспроизводит выбор сессии и переход к другому проекту.

## Ограничения реализации и проверки

- Настоящие Claude/Codex/OpenCode/Cursor не запускались для сквозного прогона новой
  эстафеты. Проверены ядро, Git, процессы через тестовые порты и настоящий GTK/RPC.
- Внешние редакторы не блокируются; точное авторство строк, shadow index,
  First-Touch Lock, выборочный reverse patch агента и автозапуск DAG вне 0.1.1.
- Грязная копия исполнителя после принятия снимка сохраняется. Очистка требует
  принятого результата, прежнего HEAD, отсутствия dirty/ignored данных.
- Архив и refs сессий не имеют автоматического GC в этой версии.
