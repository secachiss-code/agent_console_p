• Пресет Python устанавливает Ruff и Pylint. Диагностика через MCP включается в индексе проекта.
• Поиск сессий открывается из шапки. Кнопки «План», IDX и Git переключают страницы проекта.
• Настройки открываются в модальном окне. В нём можно выбрать видимые CLI и критический порог лимитов.
• Граф плана показывает направления, задачи и шаги попыток. Описание выбранной вершины остаётся открытым при наведении на другие.
• Окно лимитов показывает подписки и дневной расход токенов по моделям. Локальные логи Claude и Codex служат источником дневных рядов.
