name: aconsole-plan-node
description: Помогает разобрать блокировку, выполнить или возобновить узел плана AConsole с контекстом задачи и целевой диагностикой.
---

Для вопроса о плане читай `plan_node_get`. Запрашивай локальный `plan_graph`, когда нужны связи за пределами карточки. Для исполнения найди готовую задачу через `plan_ready` и возьми её через `node_claim`. Для L2 продолжай с `step_begin` и полученным fence. После потери контекста запроси `full_context=true`.

Для задачи без L2 собери контракт и связанные файлы одним `index_task_context`. При усечении контракта открой раздел `contract` через `plan_node_get`. Передавай `since_digest` только когда соответствующий контекст ещё доступен в диалоге. Если метод недоступен, возьми требуемый контракт и знания через доступные `plan_get` и `ctx_get`.

Для проверки правки Python вызови `index_lint(scope="node", node_id=…)`. Уточняй отдельные строки и символы через `index_read`. Сохраняй границы задачи и выполняй обязательные проверки по контракту. Вердикт и доказательства передавай через предусмотренные для задачи операции pipeline или узла.
