description: Находит исходники, определения, связанные тесты и влияние правки через индекс AConsole. Применяй для навигации по проекту и проверки затронутых Python-файлов.
---

Для обзора проекта вызови `index_overview`. Для конкретного вопроса начни с `index_find` с коротким запросом и `intent=change` или `intent=understand`. Укажи известную область, если она следует из задачи.

Перед выводом о поведении или правкой открой выбранные определения и тесты одним `index_read`, передав ссылки из выдачи и ожидаемую ревизию. Для оценки влияния используй один `index_neighbors` с несколькими целями. Для рёбер импорта входящее направление показывает потребителей, исходящее — зависимости. Связь с меткой `inferred` проверь по источнику.

При неполном покрытии уточни нужный путь локальным поиском в текущей рабочей копии. При устаревшем снимке повторно разреши только нужную ссылку. Если новые инструменты недоступны, используй `rg` и доступный `kb_impact`.

После правки Python запроси `index_lint(scope="changed")` или укажи точные цели через `scope="targets"`. Используй коды и строки из ответа для исправления. Для итоговой приёмки выполни требуемые проектом проверки.
