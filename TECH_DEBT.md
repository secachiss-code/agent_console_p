# Технический долг AConsole

## Принятые проблемы SEC-11, SEC-13 и SEC-35

Пользователь явно принял эти узлы и поручил: «Внеси проблемы в долги и закрывай».
Узлы закрываются по этому решению. Перечисленные ниже проблемы остаются открытым
долгом; исходные отрицательные результаты проверок сохраняются. Закрытие узлов
не означает устранения уязвимости, независимой security-приёмки или разрешения
установить экспериментальный runtime. Проверенная версия: `b4222eed`;
сверка SEC-35: `87533e40`.

| Долг | Приоритет | Проблема и влияние | Условие погашения |
| --- | --- | --- | --- |
| TD-SEC-11 | P1 | После перечисления безопасных настроек другой процесс может добавить новый Git filter. Последующий `status` исполняет его. Проверки известных имён и очистка окружения не закрывают гонку. | Защитить исполнение Git от поздних команд, сохранив явно разрешённые hooks; пройти исходную гонку и независимую проверку установленной границы. |
| TD-SEC-13 | P1 | В эксперименте read-only mount файла конфигурации обходится заменой `.git/config` через rename. Изменение `include.path` также использует lock/rename. Обход воспроизведён в обычном и linked репозитории. | Закрыть подмену пути и исполнение поздних команд; пройти исходные replace/include/worktree/inplace проверки с работающими native controls, затем независимую установленную приёмку. До этого эксперимент не подключать к продукту. |
| TD-SEC-35 | P3 | SEC34 закрепляет исторические hashes. После изменений четырёх UI Python-файлов исходный verifier возвращает `Source/evidence index drift`; дополнительно изменён CSS вне Python-индекса. Core и 52 upstream-файла не изменились. | Отдельно версионировать пакет для выбранной актуальной ревизии, сохранить старый, явно учесть UI/CSS delta и получить независимый review disposition. Смена hashes сама по себе не погашает долг. |

защищённая установка и независимая приёмка B01–B19. Пользовательское принятие
трёх узлов не выдаёт этим будущим этапам технический PASS.
